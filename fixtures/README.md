# Fixtures

Small media and specs for tests. Everything here is generated by FFmpeg's
built-in test sources (`scripts/gen-fixtures.sh`): no third-party content.
Dedicated to the public domain under CC0 1.0 by the repository owner.

## media/

| File | What | Notes |
|---|---|---|
| `sea.jpg`, `gradient.jpg`, `bars.jpg` | 1350x2400 JPEG | 9:16, 1.25x the output size so Ken Burns can pan |
| `wide.jpg` | 2400x1350 JPEG | 16:9, so `contain` fit shows a letterbox |
| `clip.mp4` | 720x1280, 30 fps, 6 s, H.264, no audio | `testsrc2` with a frame counter: you can see which part of the clip a render used |
| `vo-minimal.wav`, `vo-multi-1..3.wav` | 24 kHz mono WAV | Beeps, not speech: one 400 ms beep per word on a 500 ms grid |
| `music.mp3` | 44.1 kHz stereo MP3, 20 s | Soft chord |

The voice-over length is always `words * 500 ms`, and the word timings in the
specs follow the same grid, so they match the audio exactly.

## specs/

- `minimal.json`: one image scene with a voice-over.
- `cuts.json`: image with Ken Burns, trimmed clip, letterboxed landscape image,
  and a clip that ends before its scene (last frame held). Plain cuts, no audio.
  The renderer's F03 verification spec: 9500 ms, 285 frames at 30 fps.
- `multi.json`: image, video and image scenes, crossfades, music with ducking,
  word-highlight captions, overlay, loudness target.

`file://` URIs are relative to the repo root (where `just render` runs).

## Commands

- `just verify-fixtures`: checks hashes, media info and word timings, then loads
  every spec through `Retake.Spec`. This is the check.
- `just gen-fixtures`: regenerates the media and refreshes hashes, media info
  and word timings in the specs. The media is committed, so you rarely need it;
  a different FFmpeg build may produce different bytes and change every hash.
