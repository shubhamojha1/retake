## F02. Test fixtures (passing, 2026-10-03)

`fixtures/media/` holds media generated by FFmpeg's built-in sources (3 JPEGs
1350x2400, a 6 s 720x1280 H.264 clip, 4 beep voice-overs, a 20 s MP3), committed
to git. `fixtures/specs/minimal.json` and `multi.json` reference them with real
hashes, media info and word timings. Voice-overs are beeps: one 400 ms beep per
narration word on a 500 ms grid, so audio length is `words * 500 ms`.

- `just gen-fixtures` (`scripts/gen-fixtures.sh`) regenerates media and refreshes the specs.
- `just verify-fixtures` checks files, hashes, media info and word timings
  (`scripts/verify-fixtures.sh`), then loads each spec through `Retake.Spec`
  (`api/test/retake/fixtures_test.exs`). `just check` runs the bash part too.

Verification: `just verify-fixtures`. User reported it works; output not captured here.

Decisions made: media is committed (a different FFmpeg may change the bytes and
every hash); `file://` URIs are relative to the repo root (renderer rule to be
confirmed in F03).

## F03. Basic renderer (passing, 2026-10-04)

`retake_render <spec.json> [-o out.mp4]` renders image and video scenes to a
1080x1920 H.264 MP4: cover/contain fit, Ken Burns motion, clip trim, held last
frame for short clips (D13), plain cuts. Silent. Modules: `spec` (strict typed
parse + sanity checks, D15), `timeline` (boundary-rounded frame plan),
`compose` (placement maths + tiny-skia drawing), `media` (image decode, FFmpeg
clip streaming), `encode` (raw RGBA to FFmpeg), `render` (loop, warnings for
unbuilt features, D14), `main` (CLI: `progress n/total`, `done <path>`,
`warning:`/`error:` on stderr).

Sub-steps: 3a spec + timeline, 3b compositing maths with pixel tests, 3c media,
encode, render loop, CLI, `cuts.json` + `wide.jpg` fixtures, `probe-check`.

Verification: `cargo test -p retake_render` (23 unit + 12 spec + 5 basic),
`just render fixtures/specs/cuts.json` (285 frames), `just probe-check
fixtures/specs/cuts.json`. User reported the video rendered and that both
`cargo test` and `probe-check` passed; output not captured here.

Decisions: D13 (freeze short clips), D14 (warn and skip unbuilt features), D15
