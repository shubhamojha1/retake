## F02. Test fixtures (passing, 2026-10-03)

`fixtures/media/` holds media generated by FFmpeg's built-in sources (3 JPEGs
1350x2400, a 6 s 720x1280 H.264 clip, 4 beep voice-overs, a 20 s MP3), committed
to git. `fixtures/specs/minimal.json` and `multi.json` reference them with real
hashes, media info and word timings. Voice-overs are beeps: one 400 ms beep per

- `just verify-fixtures` checks files, hashes, media info and word timings
  (`scripts/verify-fixtures.sh`), then loads each spec through `Retake.Spec`

Verification: `just verify-fixtures`. User reported it works; output not captured here.

Decisions made: media is committed (a different FFmpeg may change the bytes and
every hash); `file://` URIs are relative to the repo root (renderer rule to be
confirmed in F03).

## F03. Basic renderer (passing, 2026-10-04)

`retake_render <spec.json> [-o out.mp4]` renders image and video scenes to a
1080x1920 H.264 MP4: cover/contain fit, Ken Burns motion, clip trim, held last
frame for short clips (D13), plain cuts. Silent. Modules: `spec` (strict typed
parse + sanity checks, D15), `timeline` (boundary-rounded frame plan),
`compose` (placement maths + tiny-skia drawing), `media` (image decode, FFmpeg
clip streaming), `encode` (raw RGBA to FFmpeg), `render` (loop, warnings for
unbuilt features, D14), `main` (CLI: `progress n/total`, `done <path>`,
`warning:`/`error:` on stderr).

Sub-steps: 3a spec + timeline, 3b compositing maths with pixel tests, 3c media,
encode, render loop, CLI, `cuts.json` + `wide.jpg` fixtures, `probe-check`.

Verification: `cargo test -p retake_render` (23 unit + 12 spec + 5 basic),
`just render fixtures/specs/cuts.json` (285 frames), `just probe-check
fixtures/specs/cuts.json`. User reported the video rendered and that both
`cargo test` and `probe-check` passed; output not captured here.

Decisions: D13 (freeze short clips), D14 (warn and skip unbuilt features), D15

## F05a. Voice-over audio (passing, 2026-10-04)

Each scene's voice-over is placed at scene start + `offset_ms` (start taken from
the scene's first frame, so sound and picture agree), resampled to 48 kHz
stereo, levelled by `gain_db`, mixed (`amix`, `normalize=0`), padded or cut to
the video length and muxed as AAC 128 kbps. No voice-over means no audio stream.
Code: `audio.rs` (clip placement, filter graph), `encode.rs` (extra FFmpeg
inputs), `render.rs` (clips resolved before the encoder starts). The "voice-over
not rendered" warning is gone. `probe-check` now checks the audio stream.

Tests (written first, seen failing): `tests/voiceover.rs` finds beep starts with
`silencedetect` (0.3 s offset in `minimal.json`; 0.2, 5.2, 9.7 s in `multi.json`)
and checks AAC/48 kHz/stereo/length; 6 unit tests in `audio.rs`.

Verification: `cargo test -p retake_render` (all), `just probe-check` on
`minimal.json` and `cuts.json`. User reported all pass and heard the beeps.
Also measured by hand: sound starts at 0.300 s, first beep ends 0.700 s, peak
-10.9 dB.

Left open: music, ducking, loudness (F05b); crossfades still render as cuts
(F04), so audio start times assume cuts too.

## F08. Provider config (passing, 2026-10-04)

`Retake.Providers` (api/lib/retake/providers*): `Config` loads and validates
`config/providers.toml` with `toml_elixir` (every problem reported with its TOML
path; literal `api_key` rejected, rule 7), `Provider` reads the key from the
named environment variable at call time and never stores it, `Usage` is a
GenServer for rate-limit windows (minute/hour/day/month, sliding) and budget
caps with atomic reservations (D16), and `Providers.resolve/3` + `run/5` try the
primary then the fallbacks, skipping providers with a missing key or a used-up
rate limit, charging reported cost, and stopping when the budget is spent.
`RETAKE_PROFILE` overrides the default profile. The shipped
`providers.example.toml` is loaded by the tests so it cannot go stale.

Tests: 58 across `providers/{config,provider,usage}_test.exs` and
`providers_test.exs`, written first (all red), then green. Time is passed in as
`now`, so none sleep. Verification: `mix test test/retake/providers
test/retake/providers_test.exs`; user reported all pass.

Decisions: D16 (usage counters in memory behind `Usage`), D17 (`toml_elixir`).

- `just setup` does not yet copy `providers.example.toml` to `providers.toml`.
